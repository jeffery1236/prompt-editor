# 📝 Prompt Editor

A simple web-based Prompt Editor with a Python backend and HTML frontend. Use it to structure, edit, and refine large language model prompts more efficiently.

## 🚀 Getting Started

Follow these instructions to run the Prompt Editor locally.

### 1. Backend Setup

1. Navigate to the backend directory:
   ```bash
   cd backend
   ```

2. Set up the Python environment (requires Python 3.12):

    ```bash
    poetry install
    ```
3. Add your OpenAI API key

    ```bash
    export OPENAI_API_KEY=...
    ```

4. Run the backend server:
    ```bash
    python -m main
    ```

### 2. Frontend Setup

1. Open the HTML frontend directly in your browser:

    ```bash
    /frontend/index.html
    ```
